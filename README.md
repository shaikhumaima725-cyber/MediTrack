MediTrack – Blockchain-Based Medicine Availability and Inventory Management System

📌 About the Project

MediTrack is a blockchain-based medicine availability and inventory management platform designed to improve transparency, reliability, and efficiency in the pharmaceutical supply chain.

The system connects patients, pharmacies, suppliers, and administrators through a unified platform. Patients can search for medicines and identify pharmacies reporting availability, reducing the time spent searching for essential medicines.

🎯 Key Features

* Medicine Search: Helps patients find medicines and check reported availability at pharmacies.
* Inventory Management: Allows pharmacies to add medicines, update stock quantities, and manage medicine batches.
* Blockchain Integration: Maintains a tamper-resistant and verifiable history of important inventory transactions.
* Smart Contracts: Automates authorised operations such as batch registration and stock transfers.
* Expiry Alerts: Identifies medicines approaching their expiry dates.
* Low-Stock Notifications: Alerts pharmacists when medicine quantities fall below predefined levels.
* Stockout Prediction: Estimates potential medicine shortages using current stock and average daily sales.
* Batch Traceability: Tracks medicine batches from suppliers to pharmacies.
* Admin Dashboard: Provides system monitoring, transaction tracking, and complaint management.

🛠️ Technology Stack

* Frontend: React.js, HTML, CSS, JavaScript
* Backend: Node.js, Express.js
* Database: Supabase
* Blockchain: Polygon
* Smart Contracts: Solidity
* Blockchain Integration: Ethers.js
* Wallet Integration: MetaMask

⚙️ How It Works

Suppliers register medicine batches, pharmacies manage their inventory, and important inventory transactions are recorded through blockchain smart contracts. Supabase stores regular application data, while blockchain maintains verifiable transaction records. Patients can search for medicines and view reported availability information.

🌟 Project Objective

Our objective is to develop a connected pharmaceutical inventory ecosystem that improves medicine accessibility, strengthens inventory accountability, enables batch traceability, and supports better stock management through blockchain technology.

🔮 Future Scope

Future enhancements include QR-code-based batch verification, AI-powered demand forecasting, hospital integration, and automated medicine restocking.
